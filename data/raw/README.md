# Raw Data

The raw dataset used in this project is not stored directly in this
repository.

## Primary dataset

**Dengue Environmental Variables Dataset**

Dataset:
`Dengue_Environmental Vars_Dataset.xlsx`

Maintained by:
University of the Philippines Resilience Institute (UPRI-NOAH)

Dataset DOI:
https://doi.org/10.5281/zenodo.19448854

GitHub source:
https://github.com/UPRI-NOAH/dengue-rainfall-dataset

License:
Open Data Commons Open Database License (ODC-ODbL) v1.0

## Dataset used in this project

The primary analysis uses the worksheet:

`Multi-Setting Data`

This contains weekly dengue surveillance and environmental information
for eight settings:

- Brazil
- Colombia
- Mexico
- Peru
- Philippines
- Singapore
- Sri Lanka
- Taiwan

The Multi-Setting Data sheet contains 3,216 weekly records.

## Instructions

Download:

`Dengue_Environmental Vars_Dataset.xlsx`

from the original dataset repository and place it in:

`data/raw/`

The resulting local path should be:

`data/raw/Dengue_Environmental Vars_Dataset.xlsx`

Raw data should not be manually modified. All cleaning and
transformations are performed programmatically.
